## Evidence grades

- **A — Direct measured production case:** identifiable company, intervention and measurable result, published by the company/provider/credible partner.
- **B — Official technical implementation guidance:** AWS, Microsoft, Snowflake, Databricks, Fabric and similar first-party implementation documentation.
- **C — FinOps Foundation / industry framework:** strong for definitions, methodology and conceptual backbone; not production implementation proof.
- **D — Practitioner opinion / secondary discussion:** useful for hypotheses and failure modes; never sole proof for a core portfolio claim.

`Cloud FinOps, 2nd Edition` is registered as Grade C conceptual/industry evidence for this project, with an explicit 2023-date limitation. It never overrides the current FinOps Framework.

## Source-integrity rules

1. Separate **SOURCE FACT**, **OUR ANALYSIS**, and **OUR REPRODUCTION LAB**.
2. If a case does not disclose a detail, record `Not disclosed by source` rather than filling the gap.
3. Provider recommendations are evidence inputs, not proof that a production change is safe or financially realized.
4. Projected/potential savings must not be labeled realized savings before comparable post-change billing validation.
5. Core deep case studies should rely mainly on Grade A/B evidence.
6. Market frequency is an N=7 snapshot and must retain its sample-size limitation.
